# Två spår: byggplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dela alexahman.se i två spår, `/hemsidor` (svenska) och `/systemutveckling` (svenska och engelska), bakom en ny startsida med delad skärm.

**Architecture:** Alla adresser samlas i en ren JS-modul, `src/paths.js`, som både appen, `routes.js` (förrendering och sitemap) och språkväxlingen läser från. `App.jsx` får tre skal: startsidan och en layout per spår med egen meny. Befintliga sidkomponenter flyttas in i spåren och tar emot sina adresser från `paths.js` i stället för att bygga dem själva.

**Tech Stack:** React 18, React Router 7, Vite (rolldown-vite) med `vite-prerender-plugin`, react-helmet-async, vanlig CSS i `src/styles/global.css`. Tester körs med Nodes inbyggda `node:test` (Node 25). Inga nya beroenden.

**Spec:** `docs/superpowers/specs/2026-10-16-tva-spar-design.md`

## Global Constraints

- Allt sker i grenen `feat/tva-spar`. Ingen push, ingen merge till `main` och inga ändringar i Render.
- Starta aldrig en dev-server automatiskt. Använd `npm run build` och sedan `npm run preview` (en server åt gången).
- Inga nya npm-beroenden.
- Hemsidespåret finns bara på svenska. Utvecklarspåret finns på svenska och engelska, där engelska ligger under `/en/software-development`.
- Formulärfältet för spåret heter `spår` och har värdet `hemsidor` eller `systemutveckling`.
- Priset på startsidan hämtas från `LOWEST_PRICE` i `src/packages.js`, aldrig hårdkodat.
- Accentfärger: koppar `#c8683d` för hemsidehalvan och teal `#1f8b7f` för utvecklarhalvan.
- `/hemsidor` behåller orden "hemsida" och "Västervik" i `<title>` och `h1`.
- Kod och kommentarer följer filernas stil: kommentarer på svenska, inga semikolonfria avsteg och ingen TypeScript.

## Review Focus

1. **Gamla adresser med avslutande snedstreck** (`/projects/fairway/`) ska omdirigeras precis som utan snedstreck. Testas i Task 2.
2. **Språkknappen på en sida som saknar motsvarighet** (`/hemsidor/priser`) ska leda till `/en`, aldrig till en 404. Testas i Task 1.
3. **Ett första tryck på mobil** på en halva av startsidan ska navigera direkt, inte bara "aktivera hover". Testas i Task 6.
4. **En video som inte kan laddas** (filen saknas eller nätverket är långsamt) ska lämna stillbilden synlig, utan tom eller svart yta. Testas i Task 7.
5. **Lördagsgolf under `/hemsidor/exempel/lordagsgolf`** ska ha en canonical som pekar på `/systemutveckling/projekt/lordagsgolf`. Testas i Task 4.

import { ROUTES, REDIRECTS } from "../src/routes.js";

test("ROUTES har inga dubbletter och inga gamla adresser", () => {
  assert.equal(new Set(ROUTES).size, ROUTES.length);

    assert.ok(!ROUTES.includes(old), old);
